# Poitters-Point-
ポイッターズポイントガワ借り制作

## クローンと素材ファイル(Git LFS)について

モデルや画像などの大きなファイルは Git LFS で管理しています。クローンの前に、各PCで一度だけ `git lfs install` を実行してください。

### .fbx は自動ではダウンロードされません

`.fbx`(モデル・アニメーションの元データ)はゲームの実行に使わない(ゲームは `.mv1` を読み込む)ため、
クローンやプルを軽くする目的で、本体を自動ではダウンロードしない設定にしています(`.lfsconfig`)。

- ビルド・実行・普段の開発では、何もする必要はありません。
- `.fbx` は 130 バイトほどの小さなテキストファイル(LFSのポインタ)として置かれます。ファイル名や場所は同じですが、中身はモデルではありません。

### .fbx を開く・変換する人(Blender で編集する、`.mv1` に変換し直す など)

作業の前に、そのPCで次のコマンドを実行して `.fbx` の本体を取得してください(SourceTree なら右上の「ターミナル」から実行できます)。

```
git lfs pull -I "*.fbx" -X ""
```

特定のファイルだけ取得する場合は、`-I` にそのファイルのパスを指定します。

```
git lfs pull -I "BaseProject2026_0613/data/Game/Models/Enemy/Enemy.fbx" -X ""
```

- 取得せずにポインタのまま開くと「ファイルが壊れている」「読み込めない」といったエラーになります。その場合は上のコマンドを実行してください。
- `.fbx` の追加・更新は、今までどおりコミットしてプッシュすれば本体もアップロードされます。既存の `.fbx` を上書きする場合は、先に本体を取得してから作業してください。
